# Beoma Skills — инструкции для агентов

Этот приватный репозиторий хранит переносимые скиллы Beoma. Канон — `skills/<name>/SKILL.md`; установленные папки не редактировать.

## Разработка
Python 3.10+, стандартная библиотека, Git. Проверка: `python3 scripts/check.py`, затем `python3 -m unittest discover -s tests -v`.

## Архитектура и конвенции
- Один скилл — одна папка, имя с префиксом `beoma-`, lowercase/kebab-case.
- Frontmatter: `name` и однострочная `description`; инструкция на русском, независима от конкретного агента.
- Объёмные условные проверки — `references/`, дополнительные ресурсы только по необходимости.
- Пути относительно папки скилла; инструменты выбираются из доступных в текущей сессии. Не выдумывать MCP или команды.
- При изменении установщика проверять повторную установку, конфликты и сохранение чужих файлов.
- Обновлять `docs/distribution.md`, если меняются пути агентов или механизм доставки.

## Безопасность и Git
Не включать токены, бизнес-данные, персональные скриншоты. Не переносить чужие личные скиллы без проверки прав и содержания. Локальные пути не публиковать в GitHub-документации. Не коммитить и не отправлять изменения без запроса владельца.

## Особенности
`skills/` сама по себе не обнаруживается агентами. Установщик копирует её в native-каталоги. Текущие сессии могут потребовать перезапуска. Глобальная установка не гарантирует наличие скиллов в облаке.
