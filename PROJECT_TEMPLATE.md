# Beoma Skills

## Гипотеза
Единый каталог проверенных процедур сократит повторное объяснение требований и расхождения между агентами. Основание — запрос владельца проекта; эффект пока не измерен.

## Целевая метрика
Предлагаемая MVP-метрика: сократить медианное время подготовки агента к UI-ревью на 30% относительно ручных инструкций. Это целевой ориентир, не подтверждённый бизнес-эффект.

## MVP-тест
Один скилл UI-ревью, два проекта, четыре агента. На одинаковых экранах сравнить время запуска, обнаруженные подтверждённые дефекты и ложные замечания с ручным ревью.

## Критерий успеха / провала
Предлагаемый порог: установка проходит в 4/4 агентах; экономия времени ≥30%; доля ложных замечаний ≤10%. Без живых прогонов масштабирование не считать подтверждённым.

## Альтернативы
Ручные промпты; отдельные каталоги каждого агента; плагины для конкретного агента. Выбран переносимый SKILL.md и установка копий.

## Сложность и риски
MVP — Markdown и Python без сторонних зависимостей. Риски: различия обнаружения скиллов, устаревшие копии, недоступный приватный репозиторий в облаке. Брендовый эффект косвенный: качество интерфейсов; финансовый эффект не оценён.

## Стек и интеграции
Python 3.10+, Git, Agent Skills; Claude Code, Google Antigravity, OpenAI Codex, Cursor. API и секреты не нужны, для скачивания нужен доступ GitHub.
