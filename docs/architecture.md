# Архитектура

`skills/` — единственный источник инструкций. Python-установщик валидирует каталог и копирует выбранные скиллы в каталоги обнаружения агентов. Codex, Cursor и Antigravity используют одну физическую копию `.agents/skills`, Claude — `.claude/skills`.

Установщик хранит хеши установленных файлов и Git SHA источника в `.beoma-skills-state.json`. При повторной установке он обновляет только собственные неизменённые копии. Чужой каталог или локально изменённый скилл вызывает ошибку до записи. Удалённые из источника скиллы автоматически не удаляются; выбранный набор можно устанавливать частями.

Глобальная установка создаёт копии в пользовательских native-каталогах. Копирование переносимо между ОС; symlink и общий внешний checkout не требуются.
