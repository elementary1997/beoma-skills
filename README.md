# Beoma Skills

Общий каталог переносимых скиллов для Claude Code, Google Antigravity, OpenAI Codex и Cursor. Первый скилл — [beoma-ui-review](skills/beoma-ui-review/SKILL.md): глубокая проверка лендингов и фронтенда сервисов с интерактивным чек-листом, исправлениями и показом результата до/после.

## Установка

Нужны Python 3.10+, Git и доступ к этому приватному репозиторию.

```sh
git clone https://github.com/elementary1997/beoma-skills.git
cd beoma-skills
python3 scripts/install.py --project /path/to/consumer-repo
```

Замените пример пути на рабочий репозиторий. Команда устанавливает скиллы для всех четырёх агентов. Выбрать агента: `--agents claude codex`; выбрать скилл: `--skills beoma-ui-review`.

Для всех локальных проектов пользователя:

```sh
python3 scripts/install.py --user
```

Запустите новую сессию и проверьте список скиллов. Если имя не обнаружилось, прочитайте установленный `SKILL.md` явно и проверьте версию агента. Вызов в Codex: `$beoma-ui-review`; в Claude Code/Cursor: `/beoma-ui-review`; в Antigravity — попросите использовать скилл `beoma-ui-review`.

Пример запроса: «Используй beoma-ui-review. Проверь интерфейс на этой странице на мобильном и десктопе: выравнивание, типографику, состояния формы и ошибки. Создай интерактивный чек-лист, затем исправь подтверждённые ошибки в локальном коде и покажи до/после».

## Разработка

Канон: `skills/<name>/SKILL.md`. Правила: [AGENTS.md](AGENTS.md). Скилл содержит обязательные `name` и `description` в YAML frontmatter. Дополнительные материалы лежат внутри папки скилла. Не завязывайте общий скилл на наличие конкретного MCP.

```sh
python3 scripts/check.py
python3 -m unittest discover -s tests -v
```

CI выполняет эти же проверки. [Подключение ко всем репозиториям и ограничения](docs/distribution.md), [архитектура](docs/architecture.md), [решение о доставке](docs/adr/0001-portable-skills.md).

## Что делает UI-скилл

По умолчанию: аудит → интерактивный HTML-чек-лист → локальные исправления → повторная проверка. Для анализа без изменений явно попросите «только ревью». При отсутствии кода выполняется аудит и составляется отчёт с ограничениями.

Глубокий проход включает визуал и дизайн-систему, viewport/breakpoints, ключевые сценарии, состояние формы/таблицы/диалога, доступность, ошибки сети/runtime, производительность и применимые проверки публичного лендинга. Фактическое покрытие отражается в отчёте: непроверенное не считается пройденным.

Чек-лист показывает приоритеты, доказательства, историю исправлений, до/после, статусы и выбор задач. Галочка «исправлено и перепроверено» ставится по результату реального повторного прогона; пользовательский выбор и заметки экспортируются отдельно. Локальный HTML не отправляет изменения агенту автоматически; после генерации новой версии отчёт надо перезагрузить.

[Подробная методика](skills/beoma-ui-review/references/deep-audit.md), [контракт отчёта](skills/beoma-ui-review/references/report-workflow.md), [изученные источники](skills/beoma-ui-review/references/sources.md). Генератор отчёта использует стандартную библиотеку Python; дополнительные browser/axe/Lighthouse-инструменты берутся из доступного окружения.
